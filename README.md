# Power BI Dashboard Project

A comprehensive sales analytics dashboard built with Microsoft Power BI that transforms raw sales data into actionable business intelligence through interactive visualizations and KPI tracking.

## 🚀 Quick Start

Since this is a Power BI project (.pbix file), you cannot run it directly on GitHub. Follow these steps to view and interact with the dashboard:

### Prerequisites
- **Power BI Desktop** (free download from [Microsoft](https://powerbi.microsoft.com/desktop/))
- Windows operating system (Power BI Desktop requires Windows)

### Steps to View
1. **Clone or download** this repository to your local machine
2. **Open** `Power BI Project.pbix` with Power BI Desktop
3. **Explore** the interactive reports and visualizations

## 📊 Dashboard Features

### Analysis Views
- **Executive Summary** – Key metrics and performance overview
- **Sales Analysis** – Revenue trends and regional performance  
- **Customer Insights** – Segmentation and purchasing patterns
- **Product Analytics** – Category performance and inventory analysis

### Interactive Elements
- **Filters** – Slice data by date, region, product category
- **KPI Cards** – Monitor revenue, profit, orders, customer metrics
- **Trend Visualizations** – View daily, monthly, and yearly performance
- **Drill-through** – Click visuals for detailed insights

## 📈 Key Metrics Tracked
- **Total Revenue & Profit**
- **Order Count & Average Order Value**
- **Customer Count & Retention**
- **Regional Performance**
- **Product Category Performance**

## 🔧 Technical Implementation
- Built with **Power BI Desktop**
- Uses **DAX formulas** for calculations
- Implements **star schema** data model
- Includes **time intelligence** functions (YTD, MTD comparisons)

## 📖 How to Use the Dashboard
1. Open the `.pbix` file in Power BI Desktop
2. Use **slicers** (typically on the left/right) to filter data
3. **Hover** over charts for detailed tooltips
4. **Click** on visual elements to drill through to detailed data
5. Use **bookmarks** (if available) for preset analysis views

## 🔄 Data Refresh
To update the data in this report:
1. Click **Refresh** in the Home ribbon of Power BI Desktop
2. Or publish to **Power BI Service** and set up scheduled refresh
3. *Note: Ensure you have access to the original data sources*

## 📱 Viewing Options
- **Desktop** – Full interactive experience in Power BI Desktop
- **Web** – Publish to Power BI Service for browser-based sharing
- **Mobile** – View optimized layout in Power BI Mobile app
